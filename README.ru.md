# CloseLoom

CloseLoom — настольное приложение для Windows 11 x64. Оно наблюдает только за программами, которые вы явно выбрали. Сейчас доступен только режим **Dry Run**: приложение может записывать результаты наблюдения, но не завершает процессы. Сохраняйте работу обычным способом: CloseLoom не является резервной копией и не гарантирует сохранение данных в других программах.

## Установка в Windows 11

1. Откройте официальную страницу [GitHub Releases](https://github.com/Saidaminov-x7/CloseLoom/releases) и скачайте из выпуска `CloseLoom-win-x64.zip`.
2. Распакуйте ZIP в удобную папку и дважды щёлкните `install.cmd`.
   Установщик использует сценарии PowerShell и соблюдает действующую политику их запуска. Если неподписанные сценарии запрещены, установка и удаление могут завершиться ошибкой; пакет не изменяет и не обходит эту политику. Для надёжного запуска двойным щелчком при таких ограничениях нужен подписанный установщик.
3. Windows может попросить подтвердить запуск скачанного установщика. CloseLoom устанавливается для текущей учётной записи без прав администратора, запускается сразу и добавляется в список программ автозапуска при входе этой учётной записи.

Архив автономный: .NET уже включён, отдельно устанавливать его не нужно. Если запустить `install.cmd` из исходного клона репозитория без файлов приложения рядом, скрипт может скачать последний архив с официальной страницы GitHub Releases. Сам исходный код не является готовым приложением: для сборки нужны .NET 10 SDK и доступ к NuGet. Не запускайте установщики из неофициальных источников.

Установщик создаёт ярлык в меню «Пуск» и, если поддерживается, запись удаления в списке установленных приложений Windows. Для удаления откройте **Параметры > Приложения > Установленные приложения > CloseLoom > Удалить** либо дважды щёлкните `uninstall.cmd` в распакованной папке релиза. В установленной папке также есть сценарий удаления. Он закрывает CloseLoom и удаляет запись автозапуска, ярлыки и файлы программы. Настройки и журнал в `%LOCALAPPDATA%\CloseLoom` сохраняются. Чтобы явно удалить эти данные, передайте сценарию удаления параметр `-PurgeData`.

## Автозапуск и наблюдение

При каждом входе в Windows CloseLoom запускается в области уведомлений (системном трее) текущей учётной записи и остаётся там до выхода из приложения или завершения сеанса. Это не служба постоянной работы: приложение не работает, когда компьютер выключен, спит или находится в гибернации, а также когда пользователь вышел из системы. При блокировке экрана сеанс обычно продолжает работать. Поведение удалённого рабочего стола зависит от настроек Windows и от того, отключён сеанс или завершён.

Автоматический запуск наблюдения при старте приложения включён по умолчанию. Наблюдение начнётся только если вы выбрали и включили приложения для отслеживания. Если список пуст, CloseLoom всё равно запустится в трее и будет ожидать настройки; автоматически искать и отслеживать все программы он не будет. Наблюдение можно приостановить или остановить в приложении. Поведение при закрытии окна задаётся настройкой приложения; при выборе соответствующего режима окно скрывается, а CloseLoom остаётся в трее.

CloseLoom наблюдает окна и процессы только в текущем интерактивном сеансе пользователя. Он может не видеть программы с повышенными правами, приложения другого пользователя или сеанса, а также некоторые изменения окон. После сна/пробуждения, изменений RDP или пропуска события Windows наблюдение может запаздывать или быть неполным. Не используйте приложение как границу безопасности или как гарантию непрерывного наблюдения.

## Безопасность и конфиденциальность

Режим Dry Run принудительно включён, завершение процессов отключено. CloseLoom не закрывает выбранные приложения. Настройки и журнал хранятся локально в `%LOCALAPPDATA%\CloseLoom`; в журнале могут быть названия программ, пути к исполняемым файлам и идентификаторы процессов. Проверяйте экспортируемые журналы перед передачей другим людям. См. [заметки о безопасности](docs/SECURITY.md).

## Сборка и проверка исходного кода

Для команд ниже нужны .NET 10 SDK и доступ к NuGet:

```powershell
dotnet restore CloseLoom.sln
dotnet build CloseLoom.sln --configuration Release --no-restore -warnaserror
dotnet test CloseLoom.sln --configuration Release --no-build
dotnet format CloseLoom.sln --verify-no-changes --no-restore
```

Чтобы создать автономный ZIP для Windows x64, запустите `powershell -NoProfile -File scripts/publish-win-x64.ps1`. Скрипт не перезаписывает существующие артефакты, если явно не передан параметр `-Force`. В архив входят установщик, удаление, файлы приложения и документация. Сборка не подписана; Windows SmartScreen может показать предупреждение. Не отключайте защиту Windows ради запуска.

- `src/CloseLoom.Desktop` — интерфейс WPF и внедрение зависимостей.
- `tests` — изолированные тесты и временные тестовые окна Windows.
- `docs` — [архитектура](docs/ARCHITECTURE.md), [безопасность](docs/SECURITY.md), [тестирование](docs/TESTING.md), [руководство пользователя](docs/USER_GUIDE.md) и [переносимость](docs/PORTABILITY.md).
