# AppGuard

AppGuard — незавершённый проект приложения Windows 11 для наблюдения за программами, явно выбранными пользователем. Мониторинг и реальное завершение процессов в этой версии недоступны. Не используйте проект для управления процессами или защиты данных.

По умолчанию настройки предусматривают Dry Run. Завершение процесса отключено; закрытие окна не доказывает, что данные сохранены. Принудительное завершение может привести к потере несохранённых данных.

Для сборки нужны Windows 11 и .NET 10 SDK:

```powershell
dotnet restore AppGuard.sln
dotnet build AppGuard.sln --configuration Release
dotnet test AppGuard.sln --configuration Release
```

Для будущого ручного запуска: `dotnet run --project src/AppGuard.Desktop`. При разработке интерфейс и реальные процессы не запускались и не проверялись. Описание компонентов, ограничений и оставшейся работы приведено в [английском README](README.md) и [документации](docs/SECURITY.md). Лицензия — [MIT](LICENSE).
